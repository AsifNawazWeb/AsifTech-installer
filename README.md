# AsifTech - Downloads

Official installers for the **AsifTech** medical laboratory management software.

## Install on Windows

1. Open the [latest release](https://github.com/AsifNawazWeb/AsifTech-installer/releases/latest) and download `AsifTech-Setup-<version>-x64.exe` (64-bit) or `AsifTech-Setup-<version>-ia32.exe` (32-bit).
2. Run the setup and follow the wizard.
3. Installed copies update themselves automatically: new fixes and features are downloaded in the background and applied on restart.
